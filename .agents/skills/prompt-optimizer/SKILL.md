# Goal
Принять сырой запрос пользователя, переработать его по 4-компонентному фреймворку Google (Persona, Task, Context, Format) с учетом технических ограничений Gemini 3.8 Flash, сохранить в файл `.agent/tasks/TASK_SPEC.md` и инициировать передачу задачи агенту-исполнителю.

# Execution Workflow
1. Анализ входящего запроса:
   - Выделить цель, технический стек, ограничения и ожидаемый результат.
2. Калибровка под стандарты Gemini 3.8 Flash:
   - Разбить структуру промпта на блоки: Persona, Task, Context & Guardrails, Format & Output Specification.
   - Исключить устаревшие параметры (temperature, top_p, top_k), задать уровень мышления: thinking_level = "medium" (или "high" для сложной логики).
   - Запретить LaTeX в текстовых блоках и таблицах (писать сложность строго как O(N), O(1), сравнения как <=, >=).
   - Разделить смысловые блоки двойным переносом строки (\n\n).
3. Сохранение артефакта:
   - Создать или перезаписать файл `.agent/tasks/TASK_SPEC.md`.
   - Записать в него структурированный промпт с чек-листом верификации (Definition of Done).
4. Handoff (Передача эстафеты):
   - Вызвать передачу задачи агенту-исполнителю с передачей пути к файлу `.agent/tasks/TASK_SPEC.md`.
