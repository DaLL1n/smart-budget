# Отчет о тестировании: Обязательная установка PWA на рабочий стол

- **Тестировщик:** feature-tester
- **Статус:** SUCCESS
- **Проверено:**
  1. **Удаление лишней логики скролла:** Все экспериментальные слушатели тача, синтетические блокировки скролла и обертки `useMobileScrollStabilizer` / `MobileScrollContainer` полностью удалены.
  2. **Очищенный `MobileBottomBar`:** Док нижней мобильной навигации оставлен чистым (`fixed bottom-0 z-50` с системным отступом `safe-area-inset-bottom`), не содержит лишних слушателей.
  3. **Принудительная блокировка в мобильном браузере:**
     - В `router.tsx` добавлена проверка `isMobile && !isStandalone`.
     - При открытии сайта во вкладке браузера телефона загружается **исключительно** `<MandatoryInstallScreen />`.
     - Никакие страницы, шапки, нижние меню, данные и скроллы не рендерятся.
     - Закрыть модалку нельзя (кнопки «Позже», «Закрыть» и крестик отсутствуют).
  4. **Кнопка «Добавить на рабочий стол»:**
     - Обрабатывает событие `beforeinstallprompt` для Android (Chrome, Samsung Internet, Edge).
     - Для iOS Safari отображает четкую пошаговую инструкцию (Поделиться ⎋ ➔ На экран «Домой» ➕ ➔ Добавить).
     - Для Samsung Internet при необходимости раскрывает понятную инструкцию через меню (⋮ или ☰ ➔ Добавить на главный экран).
  5. **Разблокировка при запуске с рабочего стола:** При открытии приложения через созданный ярлык (`display-mode: standalone`) блокирующий экран отключается и загружается полноценный интерфейс без адресных строк и панелей браузера.
