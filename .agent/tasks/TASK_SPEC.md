# TASK SPECIFICATION: Перенос кнопки ИИ-генерации в основную карточку дашборда и добавление превью-модалки

## 1. PERSONA & ROLE
- Роль: Senior UI/UX Engineer & Frontend Architect.
- Стек: React 19, TypeScript, Vite, Tailwind CSS v4, Motion, Lucide React.
- Задача: 
  1. Полностью удалить отдельный лишний блок «Умный цикл питания под бюджет».
  2. Перенести главную CTA-кнопку «Сформировать рацион и список покупок с ИИ» прямо в нижнюю часть основной карточки бюджета (Hero-баннер).
  3. Реализовать стильное модальное окно-заготовку «AI-Планировщик рациона под бюджет» при клике на эту кнопку: выбор горизонта (3/7/14 дней), расчет бюджета на рацион, сводка параметров семьи/диеты.
  4. Обеспечить чистую двухколоночную сетку на десктопе и вертикальный стек на смартфонах без пустот и визуального шума.

## 2. TASK & WORKFLOW
### Шаги реализации:
1. **Шаг 1 (Модальное окно AiMealPlannerModal)**:
   - Создать компонент `AiMealPlannerModal` в `features/manage-budget` или локально в виджете:
     - Выбор горизонта: 3, 7, 14 дней.
     - Расчет целевого бюджета на рацион.
     - Сводка предпочтений (состав семьи, диеты, магазины).
     - Кнопка действия с бейджем ИИ.
     - Плавная анимация появления, закрытие по крестику, оверлею и Escape.

2. **Шаг 2 (Обновление DashboardOverview)**:
   - Удалить второй отдельный блок под карточкой бюджета.
   - Встроить кнопку вызова `AiMealPlannerModal` в нижнюю часть главной карточки бюджета.
   - Сбалансировать сетку: слева карточка бюджета, справа форма записи расхода и профиль.

3. **Шаг 3 (Верификация)**:
   - Проверить Vite HMR на http://localhost:3000/dashboard.
   - Обновить отчеты `.agent/handoff.md` и `.agent/test-report.md`.
