# TASK SPECIFICATION: Мобильная оптимизация иерархии аналитики (личной и семейной)

## 1. PERSONA & ROLE
- Роль: Senior UI/UX Engineer / Frontend Architect.
- Стек: React 19, TypeScript, Vite, Tailwind CSS v4, Motion, Lucide React.
- Задача: Оптимизировать вертикальную иерархию страниц Личной и Семейной аналитики для мобильных экранов (375px–768px):
  1. Заменить 3 вертикальные разрозненные KPI-карточки на компактный премиальный Hero-баннер статуса бюджета (остаток крупным шрифтом + мини-метрики потраченного и дневной нормы + прогресс-бар).
  2. Добавить на мобильных экранах переключатель табов для графиков («Категории» / «Динамика по дням») с сохранением сетки 50/50 на десктопах (lg).
  3. В Семейной аналитике расположить интерактивный блок участников сразу под Hero-баннером в виде удобных фильтр-карточек с долями трат.
  4. Применить дизайн-систему: жирность 700 (font-bold) вместо 900, сбалансированные цвета без неоновой кислотности (emerald-400/80, rose-400/85, teal-400), динамический негативный цвет при перерасходе бюджета.

## 2. TASK & WORKFLOW
### Шаги реализации:
1. **Шаг 1 (Личная аналитика - PersonalAnalyticsWidget)**:
   - Объединить KPI-метрики («Мой бюджет», «Средний чек в день», «Остаток бюджета») в компактный Hero-баннер.
   - Внедрить переключатель табов графиков на мобильных экранах (`sm:hidden` переключатель: «Категории продуктов» / «Динамика по дням»), а на десктопе (`lg:grid lg:grid-cols-2`) показывать оба графика бок о бок.
   - Смягчить неоновые оттенки (`teal-400`, `emerald-400/80`, `rose-400/85` при перерасходе), выставить `font-bold` (700).

2. **Шаг 2 (Семейная аналитика - FamilyAnalyticsWidget)**:
   - Преобразовать 3 KPI-карточки в семейный Hero-баннер статуса общего бюджета.
   - Разместить блок «Вклад участников в общие траты» сразу под Hero-баннером в виде удобного интерактивного фильтра.
   - Реализовать мобильные табы для графиков («Категории» / «Динамика по дням»).
   - Использовать согласованные цвета и шрифтовые начертания.

3. **Шаг 3 (Верификация)**:
   - Проверка статической типизации: `npm run lint` (`tsc --noEmit`).
   - Формирование отчетов `.agent/handoff.md` и `.agent/test-report.md`.

## 3. CONTEXT & GUARDRAILS
- Строго Tailwind v4 нативная интеграция, без LaTeX.
- Без горизонтального скролла на 375px.
- Ограничение thinking_level = "medium" / "high".
- Никаких регрессий функционала: сохранение realtime-подписки, фильтрации по датам, выбора дня на графике и удаления/восстановления чеков.
